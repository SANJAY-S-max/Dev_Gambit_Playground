Before anything else, read this one paragraph that explains
EVERYTHING in simple words:

  "You built a website that lets users log in using their
   GITHUB account instead of creating a new username and
   password. When someone clicks 'Login', your app sends
   them to GitHub. GitHub asks: 'Do you want to let this app
   read your profile?' The user clicks 'Yes', and GitHub
   sends them back to your app with a special token. Your
   app uses that token to say 'Hello, [GitHub Name]!'
   This is exactly how 'Login with Google' or 'Login with
   Facebook' works — it's called OAuth2."

That is the whole project. Now let's go DEEP into every part.

================================================================
PART 1: THE OAUTH2 FLOW (HOW IT WORKS)
================================================================

Let's look at what happens when a user visits your app.

  YOU (Browser)
        |
  1. Visits http://localhost:8080/
        v
  ┌─────────────────────────────────────────────────────┐
  │              YOUR SPRING BOOT APP                   │
  │  Spring Security intercepts: "You aren't logged in!"│
  │  Redirects user to the OAuth2 Login Page.           │
  └─────────────────────────┬───────────────────────────┘
                            |
  2. Spring redirects to /oauth2/authorization/github
                            |
                            v
  ┌─────────────────────────────────────────────────────┐
  │                    GITHUB.COM                       │
  │  User sees: "Sign in to GitHub to continue to App"  │
  │  User logs in and clicks "Authorize App"            │
  └─────────────────────────┬───────────────────────────┘
                            |
  3. GitHub redirects BACK to your app with an Auth Code
     URL: http://localhost:8080/login/oauth2/code/github?code=XYZ...
                            |
                            v
  ┌─────────────────────────────────────────────────────┐
  │              YOUR SPRING BOOT APP                   │
  │  Spring Security automatically takes that code 'XYZ'│
  │  and sends a background request to GitHub.          │
  │  Spring says: "Here is code XYZ, give me a Token!"  │
  └─────────────────────────┬───────────────────────────┘
                            |
  4. Spring calls GitHub API (background)
                            v
  ┌─────────────────────────────────────────────────────┐
  │                    GITHUB.COM                       │
  │  GitHub verifies code XYZ and returns an            │
  │  Access Token.                                      │
  └─────────────────────────┬───────────────────────────┘
                            |
  5. Spring uses Token to fetch User Profile
                            v
  ┌─────────────────────────────────────────────────────┐
  │                    GITHUB.COM                       │
  │  GitHub returns user JSON: {"name": "Sanjay", ...}  │
  └─────────────────────────┬───────────────────────────┘
                            |
  6. Spring logs the user in and loads Controller
                            v
  ┌─────────────────────────────────────────────────────┐
  │              HelloController.java                   │
  │  Returns "Welcome to Sanjay"                        │
  └─────────────────────────────────────────────────────┘

The beauty of Spring Boot is that it handles steps 2, 3, 4,
and 5 COMPLETELY AUTOMATICALLY! You don't write any of that code.
You just configure application.properties and write your controller.

FILE 2: application.properties (The OAuth2 Keys)
─────────────────────────────────────────────────────────────

  spring.security.oauth2.client.registration.github.client-id=YOUR_CLIENT_ID
  spring.security.oauth2.client.registration.github.client-secret=YOUR_CLIENT_SECRET

  PURPOSE: This is how GitHub knows WHICH app is trying to log the user in.
           
           HOW TO GET THESE:
           1. Go to GitHub.com → Settings → Developer Settings
           2. Click OAuth Apps → New OAuth App
           3. Name it "My Spring App"
           4. Set Homepage URL to "http://localhost:8080"
           5. Set Authorization callback URL to "http://localhost:8080/login/oauth2/code/github"
           6. GitHub gives you a Client ID and you generate a Client Secret.
           7. Paste them into this file!

  NOTE ON BUG FIX:
  In the old code, you had "gitHub" (capital H).
  Spring Boot expects the registration ID to be completely lowercase: "github".
  If you use "gitHub", Spring won't auto-configure the GitHub endpoints properly!

─────────────────────────────────────────────────────────────
FILE 3: SecurityConfig.java (The Rulebook)
─────────────────────────────────────────────────────────────

FULL CODE:
  @Configuration
  @EnableWebSecurity
  public class SecurityConfig {

      @Bean
      public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
          http
              .authorizeHttpRequests(authorize -> authorize
                  .anyRequest().authenticated()
              )
              .oauth2Login(Customizer.withDefaults());
              
          return http.build();
      }
  }

LINE BY LINE:

  @Configuration
  @EnableWebSecurity
  PURPOSE: Turns on Spring Security and marks this as a config class.

  public SecurityFilterChain securityFilterChain(HttpSecurity http)
  PURPOSE: Configures the security filter chain (the gatekeeper).

  .authorizeHttpRequests(authorize -> authorize.anyRequest().authenticated())
  PURPOSE: EVERY URL in this application requires the user to be logged in.
           No exceptions.

  .oauth2Login(Customizer.withDefaults())
  PURPOSE: ★ THE MAGIC METHOD ★
           Instead of `.formLogin()` or `.httpBasic()`, we tell
           Spring Security: "Use OAuth2 Login for authentication!"
           
           Because we have the `oauth2-client` dependency AND GitHub
           credentials in application.properties, Spring Boot automatically:
           - Sets up the `/login` page to show "Login with GitHub"
           - Configures the redirect to GitHub
           - Configures the callback URL receiver
           
           `Customizer.withDefaults()` = "Just use the default settings."

─────────────────────────────────────────────────────────────
FILE 4: HelloController.java (The Welcome Desk)
─────────────────────────────────────────────────────────────

FULL CODE:
  @RestController
  public class HelloController {
      
      @GetMapping("/")
      public String greet(OAuth2AuthenticationToken token) {
          if (token == null) {
              return "Welcome to Telusko, Guest!";
          }
          String name = token.getPrincipal().getAttribute("name");
          String login = token.getPrincipal().getAttribute("login");
          
          return "Welcome to Telusko, " + (name != null ? name : login) + "!";
      }
  }

LINE BY LINE:

  @RestController
  PURPOSE: "This class handles HTTP requests and returns raw data (text)."

  @GetMapping("/")
  PURPOSE: When user visits `http://localhost:8080/` (the root URL), run this.

  public String greet(OAuth2AuthenticationToken token)
  PURPOSE: ★ SPRING MAGIC ★
           Spring automatically injects the `OAuth2AuthenticationToken`
           into your method. This object contains EVERYTHING GitHub
           sent back about the user!

  if (token == null)
  PURPOSE: A safety check. If for some reason the token is null (e.g. if
           you disabled security or added permitAll() later), don't crash.

  String name = token.getPrincipal().getAttribute("name");
  String login = token.getPrincipal().getAttribute("login");
  PURPOSE: `token.getPrincipal()` = The logged-in user's profile.
           `.getAttribute("name")` = Gets their Real Name from GitHub profile.
           `.getAttribute("login")` = Gets their GitHub Username.
           
           Why both? Some GitHub users don't set a public Name, they only
           have a Username (login).

  return "Welcome to Telusko, " + (name != null ? name : login) + "!";
  PURPOSE: Returns the greeting text.
           `(name != null ? name : login)` is a Java ternary operator.
           It means: "If name is not null, use name. Otherwise, use login."

PART 3: ALL ERRORS FOUND AND FIXED (Summary)
================================================================

  BUG 1: pom.xml — Spring Boot version 4.1.1 doesn't exist
          FIX: Changed to 3.3.4 (the current real version).
          Without this, Maven fails completely.

  BUG 2: pom.xml — Typo in "spring-boot-starter-outh2-client"
          FIX: Changed to "spring-boot-starter-oauth2-client" (added 'a').
          Without this, OAuth2 classes wouldn't exist!

  BUG 3: pom.xml — "spring-boot-starter-webmvc" doesn't exist
          FIX: Changed to "spring-boot-starter-web".

  BUG 4: pom.xml — "spring-boot-starter-security-test" doesn't exist
          FIX: Changed to "spring-boot-starter-test".

  BUG 5: application.properties — Capital 'H' in GitHub
          OLD: spring.security.oauth2.client.registration.gitHub...
          NEW: spring.security.oauth2.client.registration.github...
          WHY: Spring Boot's auto-configuration looks for known providers
               like "github", "google", "facebook" (all lowercase).
               If you use camelCase, Spring treats it as a custom provider
               and demands extra configuration!

  BUG 6: HelloController.java — Unhandled Null Token
          OLD: System.out.println(token.getPrincipal());
          NEW: Added if (token == null) check and extracted name/login cleanly.
          WHY: If someone visits the page without authentication (if rules change),
               the old code would throw a NullPointerException and crash.

PART 4: HOW TO TEST THIS APP
================================================================

1. Go to GitHub and register a new OAuth App.
2. Get the Client ID and Client Secret.
3. Open `application.properties` and paste them in.
4. Run the Spring Boot application.
5. Open your browser and go to `http://localhost:8080/`.
6. You will be redirected to GitHub automatically.
7. Log in to GitHub and click "Authorize".
8. GitHub redirects you back to your app.
9. You will see: "Welcome to Telusko, Your Name!"
