  HOW TO CATEGORIZE A NEW FOLDER (FOR AI ASSISTANT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  When a new folder appears in _Inbox/, analyze it and move it:

  IF contains pom.xml + web.xml + .jsp files
      → Java_Stack/JSP_Servlet_Projects/

  IF contains pom.xml + application.properties + @SpringBootApplication
      → Java_Stack/Spring_Projects/

  IF contains pom.xml + persistence.xml OR @Entity classes
      → Java_Stack/Hibernate_JPA/

  IF contains .java files only (no web layer, no framework)
      → Java_Stack/Other_Java/

  IF contains package.json + React / JSX files (src/App.jsx or App.js)
      → MERN_Stack/Frontend/

  IF contains index.html / .html / .css / .js only (no framework)
      → MERN_Stack/Frontend/

  IF contains package.json + express + server.js / app.js (no React)
      → MERN_Stack/Node_Express/

  IF contains Tomcat server installation (bin/startup.bat present)
      → tomcat/

  IF a COMPLETELY NEW STACK (e.g., Python, Django, PHP, etc.)
      → Create a NEW top-level folder: e.g., Python_Stack/
      → Update this FOLDER_STRUCTURE.txt with the new stack details
      → Update README.md stacks table and folder layout
